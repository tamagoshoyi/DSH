## 二、事件日志里真正的问题：USB 存储设备风暴

系统日志 `System`，近 26 小时共 **643 条** `disk`(153) / `UASPStor`(129) 事件，分布极不均匀：

事件内容：

```
Id=153 disk      : The IO operation at logical block address 0x5fc308 for Disk 1
                   (PDO name: \Device\000000de) was retried.
Id=129 UASPStor  : Reset to device, \Device\RaidPort47, was issued.
```

关键点：

- 出问题的是 **Disk 1**，不是系统盘。`disk\Enum` 里只登记了一块物理盘 `WD Blue SN580 1TB`（Disk 0），
  `UASPStor\Enum` 现在是空的——**说明 Disk 1 是一个 USB 接的存储设备（走 UASP 协议），当前已不在系统里**。
- PDO 名在 21:48 之后从 `\Device\000000de` 变成 `\Device\00000066`、`00000097`、`000000b6`… 不断变化，
  是设备反复重新枚举的典型特征。
- 报错 LBA 反复落在 0x5b1f20 / 0x600800 / 0x800 这些位置，同一批扇区读不出来。

## 四、结论

**这不是显卡/驱动崩溃，也不是内存耗尽。** 依据：

- 没有 `Kernel-Power 41`、没有 `BugCheck 1001`、`Minidump` 目录为空、无 `MEMORY.DMP`
  → 不是蓝屏，也不是直接断电；
- 是**存储 I/O 被一个反复掉线的 USB 设备拖死**，系统进入「能跑但什么都要等几十秒」的半死状态，
  直观表现就是黑屏/卡死，只能硬重启。

22:00 之后归零，说明那个设备现在不在系统里（被拔掉或彻底掉线了）。

## 五、需要用户确认

19:50 前后是否插过/拔过以下东西：U 盘、移动硬盘、USB 硬盘盒、读卡器、USB Hub、VR/眼动仪之类的 USB 设备？
现在机箱上插着哪些 USB 存储？

## 六、建议

1. **定位那个设备**：换一个 USB 口（优先主板后置直连口，避开前面板/hub），换线。
2. **关掉 USB 选择性暂停**：电源选项 → USB 设置 → USB 选择性暂停 → 已禁用。
   长时间游戏时 USB 供电波动更容易让桥接芯片掉线。
3. 如果是 USB 硬盘盒：查桥接芯片是否过热、供电是否够（带外接电源的盒子更稳）。
4. 后续再出现时，第一时间看 `Get-WinEvent -FilterHashtable @{LogName='System'; Id=129,153}` 是否同步暴涨，
   这是最直接的判据。

## 七、附带观察：页面文件确实在用
